Este sitio

Este sitio no utiliza ninguna cookie, ningún tracker ni ningún análisis de audiencia, y no contiene ningún formulario: PronoEuroX no recoge ningún dato personal a través de este sitio.

Compra

El pago lo gestiona un proveedor de pago seguro; PronoEuroX no recibe ni conserva los datos de la tarjeta bancaria. El correo electrónico del comprador se utiliza únicamente para entregar el enlace de descarga y para responder a las preguntas de facturación.

Software

Contacto

Los mensajes recibidos sólo se utilizan para responder.

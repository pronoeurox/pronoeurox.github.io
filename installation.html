Installer PronoEuroX

Tutoriel Windows 10 — 5 minutes chrono

Acheter sur Lemon Squeezy

Prérequis

  • Système : Windows 10 (64 bits). Windows 11 non testé.
  • Espace disque : 200 Mo minimum
  • RAM : 2 Go minimum
  • Connexion Internet : requise uniquement pour l'activation de la licence (puis logiciel 100 % offline)
  • Compte Lemon Squeezy : pour acheter et recevoir la clé d'activation

Étape 1 — Acheter la licence

  1. Allez sur la page de paiement Lemon Squeezy
  2. Remplissez le formulaire (carte bancaire ou PayPal)
  3. Vous recevez un email de confirmation avec votre clé d'activation
  4. Gardez cette clé, elle sera demandée au premier lancement
⚠️ Article L221-28 13° du Code de la consommation : en achetant ce logiciel numérique, vous consentez expressément à ce que l'exécution commence avant l'expiration du délai de rétractation de 14 jours, vous renoncez expressément à ce droit, et vous confirmez cette renonciation sur un support durable (email de confirmation). Aucun remboursement n'est possible après livraison de la clé.

Étape 2 — Télécharger l'installateur

  1. Dans l'email de confirmation Lemon Squeezy, cliquez sur le lien de téléchargement
  2. Vous obtenez PronoEuroX_Setup_v1.0.27.exe (~47 Mo)
  3. Enregistrez-le sur votre Bureau ou dans C:\Temp\

Étape 3 — Lancer l'installation

  1. Double-cliquez sur PronoEuroX_Setup_v1.0.27.exe
  2. Windows SmartScreen affiche : "Windows a protégé votre ordinateur — Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue"
  3. Cliquez sur "Informations complémentaires"
  4. Cliquez sur "Exécuter quand même"
⚠️ SmartScreen — c'est normal. PronoEuroX est signé par un éditeur indépendant dont le certificat n'est pas dans la base Microsoft. Cette alerte apparaît pour TOUS les logiciels d'éditeurs non mainstream. Aucune inquiétude.
  1. L'installateur Inno Setup s'ouvre
  2. Choisissez la langue (Français par défaut)
  3. Acceptez la licence MIT
  4. Choisissez le dossier d'installation (par défaut : C:\Program Files (x86)\PronoEuroX\)
  5. Cochez "Créer une icône sur le Bureau"
  6. Cliquez "Installer"
  7. Attendez 10-20 secondes
  8. Cliquez "Terminer"

Étape 4 — Premier lancement et activation

  1. Lancez PronoEuroX depuis le Bureau ou le menu Démarrer
  2. Si SmartScreen se redéclenche, même manipulation : "Informations complémentaires" → "Exécuter quand même"
  3. Une fenêtre d'activation apparaît
  4. Collez votre clé d'activation reçue par email
  5. Votre email d'achat (utilisé pour l'activation)
  6. Cliquez "Activer"
  7. Activation validée par le serveur Lemon Squeezy (~5 secondes)
  8. Le logiciel se lance
ℹ️ Activation hors-ligne possible : si vous n'avez pas Internet au moment de l'activation, contactez-nous via l'email de confirmation LS pour recevoir un fichier de licence manuel. Une fois activé, le logiciel fonctionne 100 % sans Internet.

Étape 5 — Configuration initiale

  1. Choisissez la langue de l'interface (FR / EN / ES)
  2. Sélectionnez votre pays dans la liste des 9 pays Euromillions
  3. Le logiciel charge automatiquement les 1979 tirages historiques depuis février 2004
  4. Le tableau de bord s'affiche avec les statistiques globales

Étape 6 — Premiers pas

Vous êtes prêt. Voici les onglets principaux :

  • Fréquences : tableau des 50 numéros et 12 étoiles avec leur nombre d'apparitions et leur retard actuel
  • Cycles : analyse des cycles moyens d'apparition par numéro
  • Corrélations : matrice des corrélations entre numéros et entre étoiles
  • Combinaisons : générateur de grilles avec filtres (pair/impair, somme, distribution)
  • Aide : documentation complète intégrée (index des rubriques)

Dépannage

❓ SmartScreen se déclenche à chaque lancement
C'est le comportement normal pour un éditeur non reconnu. À chaque fois : "Informations complémentaires" → "Exécuter quand même". Pour éviter cela à l'avenir, ajoutez PronoEuroX aux applications approuvées par Windows Defender.
❓ "La clé d'activation est invalide"
Vérifiez que vous avez copié la clé COMPLÈTE (sans espace avant/après). Si le problème persiste, attendez 60 secondes (synchronisation serveur LS) et réessayez.
❓ L'installateur ne se lance pas (rien ne se passe)
Vérifiez que vous êtes bien sur Windows 10 64 bits (Clic droit sur "Ce PC" → Propriétés → Type du système). Si vous êtes en Windows 11, le logiciel n'est pas garanti compatible.
❓ Le logiciel se lance mais les données ne se chargent pas
Vérifiez votre connexion Internet au premier lancement. Les 1979 tirages sont téléchargés depuis les archives publiques FDJ. Si vous êtes derrière un proxy d'entreprise, désactivez-le pour le premier lancement.
❓ Aucune aide technique disponible
Rappel : aucun support technique n'est garanti. Le logiciel est vendu "tel quel". Consultez la FAQ pour les questions courantes.

Mises à jour

Aucune mise à jour n'est garantie. Si l'auteur publie une mise à jour, elle sera annoncée sur la page principale. Vous pouvez vérifier manuellement votre version actuelle dans le menu Aide → À propos.

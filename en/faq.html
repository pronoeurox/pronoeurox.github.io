Frequently asked questions

What is PronoEuroX?

PronoEuroX is a Windows statistical analysis software for Euromillions. It loads 1,979 draws since February 2004 and computes frequencies, delays, cycles, correlations and filtered combinations for the 5 main numbers (1-50) and 2 lucky stars (1-12).

No. No software can predict a lottery draw (jackpot probability: 1 in 139,838,160). PronoEuroX is a statistical data exploration tool, not a prediction system.

What are the main statistical features?

Appearance frequencies per number/star, delays (draws since last appearance), average cycles, correlations between numbers, correlations between stars, filtered combination generator (odd/even, sum, decade distribution, consecutives).

How many languages are available?

How does the multi-year selector work?

The main banner lets you select a year range (for example 2010-2020) to recalculate all statistics on the chosen period. This is useful to compare eras or exclude atypical years.

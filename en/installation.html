Step 2 — Download the installer

  1. Double-click PronoEuroX_Setup_v1.0.27.exe

  4. Click "Run anyway"

  1. Launch PronoEuroX from the Desktop or the Start menu

Troubleshooting

❓ SmartScreen triggers at every launch
This is the normal behaviour for an unrecognised publisher. Each time: "More info" → "Run anyway". To avoid this in the future, add PronoEuroX to the apps approved by Windows Defender.
❓ The installer does not launch (nothing happens)
Check that you are on Windows 10 64-bit (Right-click on "This PC" → Properties → System type). If you are on Windows 11, software compatibility is not guaranteed.
❓ The software launches but data does not load
Check your Internet connection on first launch. The 1,979 draws are downloaded from the FDJ public archives. If you are behind a corporate proxy, disable it for the first launch.
